# Three Apify Actors: app reviews, Google Ads Transparency and Google Hotels

Built by Aniruddha Garje. The Actors are live on the Apify Store:

- [App Store & Google Play Reviews Scraper](https://apify.com/garje/app-store-play-reviews-scraper)
- [Google Ads Transparency Scraper](https://apify.com/garje/google-ads-transparency-scraper)
- [Google Hotels Scraper](https://apify.com/garje/google-hotels-scraper)

Start with [PROJECT_GUIDE.md](PROJECT_GUIDE.md). It explains what each Actor does, how the code is laid out, how to run the tests and the rules the code follows.

Test fixtures are saved real responses from the public sources, with reviewer, contributor and individual advertiser names replaced by placeholders.
